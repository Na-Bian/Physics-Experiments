- 用 `xelatex 文件名.tex` 即可重新编译生成对应的 `.pdf`。
- 个别实验（分光计的使用、转动惯量与杨氏模量的测量、霍尔效应）仅提供 `.pdf`，暂无 `.tex` 源文件。
